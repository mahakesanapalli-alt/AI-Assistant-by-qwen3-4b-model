# AI-Assistant-by-qwen3-4b-model
SkillBridge AI is an AI-powered project mentor built with React, Python, FastAPI, and Qwen3:4B via Ollama. It aims to help students analyze projects, generate development roadmaps, and receive step-by-step guidance. Currently in early development, this project is part of my journey as a Diploma student exploring AI and full-stack development.
